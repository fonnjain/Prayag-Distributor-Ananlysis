## 3. Output formats do not match the specification

The pack is entirely **HTML**. The requirement was **PDF for reports and PPTX for the deck**.

`AiReports.tsx` already contains `exportSectionsPdf`, `exportPerformanceReviewPdf`, `exportSuggestionsPdf` and `exportTravelPlanPdf`. So an individual download produces PDF while the batch zip produces HTML — **the same content in two formats depending on how it was requested.**

Report:

- Whether the batch path can call the same export functions the individual path uses
- What prevents it today, if anything
- Whether the deck can be produced as **PPTX** rather than HTML

An HTML deck cannot be opened in PowerPoint or edited before a review meeting, which is most of the reason a deck is wanted at all.

**Do not rebuild the pack until this is answered.** If the batch path can reuse the existing exporters, that is a small change and the pack should be regenerated once, in the right formats.
