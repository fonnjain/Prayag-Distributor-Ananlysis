# Application QA — Prayag Sales Intelligence

**Page by page, with expected values**
*21 August 2026*

---

## How to use this

Work top to bottom. **Section A gates everything** — if the anchors are wrong, every page below is wrong and testing them wastes time.

Each page lists **what to check**, **what a pass looks like**, and **the trap** — the thing most likely to be broken and least likely to be noticed.

Where a figure appears, it is the expected value. Anything else is a fail.

> **Two rules that override everything else.** A number must never change because of a display action. And the same figure on two pages must agree — cross-page disagreement is the most common real defect and section G is dedicated to it.

# G · Cross-page consistency

**The most valuable section.** Same figure, two pages — they must agree.

| Figure | Page A | Page B |
|---|---|---|
| FY2025-26 total | Overview ₹360.99 Cr | Company Reports |
| FY2026-27 YTD | Overview ₹104.91 Cr | Momentum |
| Retailer count | Coverage 18,117 | Customer Data |
| Active retailers | ~5,485 | Organisation → Customers |
| Alert count | Red Alert page | Weekly digest |
| Segment net | SKU Overview | Company Reports |
| Customer net | Rankings | Distributor Deep Dive |
| MRP for one code | MRP Master | Calculator, Price Shrinkers |
| Head team size | Organisation → People | Coverage |

**Method:** pick one head and one state. Read every figure for them on every page. Any disagreement is a real defect.

# I · Traps worth knowing

Each cost real time to find.

| Trap | Where it bites |
|---|---|
| Absence rendered as zero | "No target recorded" ≠ 0% |
| A state flag trusted over the data | A month marked complete with zero rows |
| Fuzzy match before exact | 130-B truncated to 130 |
| Head resolved by string | SANDEEP JI, RIZVI JI, BIJJU are pack forms |
| A hardcoded count in a header | "179 people" beside "0 of 0 shown" |
| Two lists that must agree | They will diverge |
| A date wrong while its label is right | The workbook year defect |
| Stale deployment serving old routes | The card that read 42 for days |
| Reason and operator in one column | "Who did this" loses its answer |
