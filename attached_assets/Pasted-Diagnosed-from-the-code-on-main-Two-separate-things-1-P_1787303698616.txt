Organization page, dropped in as a second tab. All the edit machinery on that

tab only.

So the screenshot is expected, but wrong. The collision warnings it shows -
"Employee code 210 collision", 424, 957 - are precisely what someone would
want to fix in place.

Make the registry editable, with the same pattern as the People tab:
  - Edit canonical name, alias_primary, alias_secondary, reports_to,

    changes affect historical attribution

    in reason
