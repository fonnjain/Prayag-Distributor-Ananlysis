### B4 — the month-range label will start lying

```
Code change. One operator.

formatRecordedMonthRange uses:

  members.some((member) => member.monthlyNotYetRecorded?.[idx] === false)

"some" - a month counts as recorded for the label if ANY member has it recorded.
But the denominator is per-member: each member's plan enters
secondaryPlanRecorded only for months where THAT member's month is recorded.

Today they agree because August is unrecorded for everyone. They diverge the
moment August closes unevenly - one member of Sandeep's 75 gets August recorded
and the label flips to Apr-Aug while the denominator is still mostly Apr-Jul.

Change it so the label reflects what the denominator actually covers. I prefer
the strict reading: a month counts only when every contributing member has it
recorded. That errs toward a shorter range than reality, which understates
coverage rather than overstating it.

Show me both options with their consequences before choosing.
```
