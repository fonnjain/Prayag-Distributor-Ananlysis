Bug 1: Company Reports prior-year column reads zero

Report 1, sale by state, Apr–Jul FY2026-27 vs FY2025-26:

State	FY2026-27	FY2025-26	Growth
WEST BENGAL	₹20.53 Cr	₹0.00 Cr	—
UTTAR PRADESH	₹12.30 Cr	₹0.00 Cr	—
BIHAR	₹9.44 Cr	₹0.00 Cr	—

FY2025-26 is frozen at 145,613 rows and ₹361.00 Cr. It is not empty. Apr–Jul of that year is roughly a third of it.

Likely cause: state name vocabulary. This report groups by state. FY2025-26 rows carry state_canon values like UP ( R ), DELHI A, KARNATAKA (B) — territory splits. The current-year column shows UTTAR PRADESH, WEST BENGAL — canonical names. If the join is on raw values, the two years never match and every prior cell is empty.

This is the same stateCanon normalisation issue already fixed in the Customer Performance filter. The shared module exists; this report is not using it.

The like-months banner is correct and worth keeping — "comparing Apr–Jul FY2026-27 against the same Apr–Jul months of FY2025-26. Incomplete current year — never compare to full prior year." That rule is right. Only the join is broken.
