Phase A2 - one report, end to end, with the numeric guard
PROMPT - Phase A2
Prayag app - AI Analytics, Phase A2 of 7. Same global rules. Depends on A1.

Goal: generate ONE artifact end to end - the salesperson detailed report as a PDF -
and prove the whole chain works before building the rest.

Chain: payload from A1  ->  Anthropic API  ->  structured JSON response  ->  numeric
guard  ->  app renders PDF. Claude never emits a file and never computes a number.

1. The generation call. Send the A1 payload with a system prompt that states, in
   these terms:
     - Use ONLY figures present in the supplied payload. Never calculate a new number,
       never derive a ratio, never estimate, never round into a different value.
     - Every quantitative claim must reference the payload field it came from.
     - Where a dataQuality flag bears on a claim, state the caveat in the same
       sentence as the claim - not in a footnote.
     - Write in English. No emojis. Do not address the salesperson directly; this is
       written for management.
     - If the payload lacks what a section needs, write that it is unavailable and why.
       Never fill a gap with a plausible figure.
   Ask for a JSON response with a fixed section structure: executive summary,
   performance against target, coverage and customer base, visit effectiveness,
   cost and return, risks and data caveats.

2. THE NUMERIC GUARD. After the response returns and before rendering, extract every
   number from the generated text and check each against the payload, allowing for
   formatting variants (lakh/crore notation, thousands separators, one decimal place
   of rounding, and percentages given to one decimal). Any number that cannot be
   matched to a payload field is flagged.
     - Log every unmatched number with its surrounding sentence.
     - Mark the report 'requires review' rather than silently publishing it.
     - Do NOT auto-correct the text - surface it.
   This guard is the single most important safeguard in the feature. It is what stops
   a fluent, wrong figure reaching a manager's desk.

3. Render the PDF in the app from the returned JSON. Include a footer on every page
   carrying: data cutoff, generation timestamp, and the source note that figures are
   computed by the application and narrative generated by Claude.
