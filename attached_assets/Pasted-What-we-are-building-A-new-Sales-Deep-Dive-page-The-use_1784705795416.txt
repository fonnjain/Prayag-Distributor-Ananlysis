What we are building
A new 'Sales Deep Dive' page. The user picks a State Head, then a team member under that head, then a fiscal year, and sees that member's full performance profile. FY2024-25 and FY2025-26 are frozen (served from the database once loaded and verified, never re-read from Sheets). FY2026-27 is live and auto-derived.
Sourcing model (route B = re-derive, with source A as cross-check)
- Mandatory KPI set (the minimum) = the ~38 fields from the Anant Singh legend tab, columns through AP. Read per member from the STATE HEAD DASHBOARD 'Data' tab (source A) for the live year, and from the frozen DB for closed years.
- Retailer-level detail (per-retailer OB / Sale / plan / visits / distance) is re-derived (source B) from each member's own working sheet. This powers spread, visit analysis, and the auto visit plan.
- SKU / segment spread comes from secondary_register_line (already loaded from the segment-wise registers): item-code + segment for closed years; segment-level only for the live year (no FY2026-27 register exists yet, so item-code auto-fills later).
- Cost (CTC, T.A.) comes from the dashboard 'Data' tab / HR. ROI is revenue-to-cost now; margin-based ROI is added later when a cost master (fg_cost) is populated.
Non-negotiable rules (apply to every phase)
- 1. NET = Sub Total, never Order Total.
- 2. Achievement is always recomputed (received / plan), never read from a sheet's own percent cell; numerator and denominator must cover the same population.
- 3. The State Head Dashboard is the authority for headline secondary OB and sales; the register is drill-down only.
- 4. Keep the four measures distinct, and keep direct-dealer separate from retailer/party business on every figure.
- 5. Match member names with the secondary key (normSecKey) that PRESERVES parentheticals like (Off Roll) and (Rudrapur). Never apply the primary canonHead() to secondary names, and never match a member by row number.
- 6. Closed years (isClosedFy = true) are frozen: once loaded and verified, serve from the DB and never read Sheets for them again.
- 7. Corrections supersede (version_status), never DELETE. All inserts ON CONFLICT DO NOTHING. Count occurrence over all rows before filtering.
- 8. Logging via pino (req.log in handlers, logger elsewhere) - never console.log. Config JSON must be statically imported (no fs.readFileSync(process.cwd())). Read PORT from env. Match tab names with startsWith (titles truncate to 31 chars). Coerce string numeric cells via the sheets.ts helpers.
- 9. New API route = add the handler, add it to openapi.yaml, run codegen, validate inputs with Zod, then RESTART the API server.
- 10. Google Drive stays strictly read-only. No writes, deletes, moves, renames.
- 11. No emojis anywhere.
- 12. Never trust a self-report of success. Prove each result with a COUNT(*) or a reconciliation to a known number. A total that looks right is often inflated - trace one row source to screen.
