# Prompt Index

Numbering starts at P001, 14 September 2026. Earlier prompts were unnumbered.

**Convention**

```
P<nnn>_<APP>_<Short_name>.md
```

`APP` is the application the prompt is for, so it cannot be pasted into the wrong agent:

| Tag | Application | Repository |
|---|---|---|
| `COMPETITION` | prayag-price.com | `fonnjain/Prayag-Competition-Analysis` |
| `SALES` | prayag-sales.com | `fonnjain/Prayag-Distributor-Ananlysis` |

Each prompt carries its number in a banner under the title, and asks the agent to quote it when reporting back. That way a report can be matched to the prompt that produced it without guessing.
