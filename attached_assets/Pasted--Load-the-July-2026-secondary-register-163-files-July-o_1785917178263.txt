## Two things worth passing back to the business

**A State Head is being exported as a salesperson, twice running.** `SANDEEP DADHEECH` and `SANDEEP AMRUT SONAWANE` are byte-identical in both drops. That is a fault in whatever generates these files, and it will recur every month until someone fixes it.

**The same thirteen duplicate pairs appear each time.** Resolving them here works, but it is manual effort repeated monthly. Worth asking whether the export can emit one file per PS code rather than one per name variant.
