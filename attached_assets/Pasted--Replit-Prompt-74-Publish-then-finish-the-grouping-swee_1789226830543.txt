## Notes

- **Section A first**, because verified-but-uncommitted work is the state that gets
  lost. The same pattern earlier this week left 45 commits unpushed across
  fourteen deploys.
- **B4 is the one I would read first.** A single view drawing one column from the
  registry and another from `group_canon` would produce a table that does not add
  up, and it would be very hard to spot from the screen.
- **B5's scheme caveat is not theoretical.** Scheme eligibility runs on
  `scheme_item_group.item_group`, a separate 22-value vocabulary. If a category
  remap can shift a slab or a nudge, that is money moving because someone
  retagged a product — and it needs an explicit barrier rather than an assumption.
