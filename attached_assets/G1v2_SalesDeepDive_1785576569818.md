# Part 1 — Member KPIs

| Term | Definition |
|---|---|
| **Primary Target (YTD)** | target for direct billing, company to distributor or dealer |
| **Secondary Target (YTD)** | target for orders booked by the rep from retailers to distributors |
| **Order Booking (Secondary)** | value of secondary orders from retailers. **Net = Sub Total, excluding taxes** |
| **Direct Dealers Order** | orders booked directly from dealers — **kept separate** from retailer OB |
| **Sale (Sales Received)** | actual secondary revenue received |
| **CTC** | cost to company — the member's salary cost |
| **T.A. Bill + Station Cost** | YTD cumulative travel and station expense |
| **Cost Ratio** | total cost as a percentage of sales received |
| **Total Visits (YTD)** | all visits — retailer, distributor, direct dealer, leads |

# Part 2 — Achievement: four ratios, never one

| Ratio | Formula |
|---|---|
| Secondary | secondary OB ÷ secondary target |
| Direct dealer | DD order ÷ primary target |
| Total | (secondary + DD) ÷ total target |
| Sale | sales received ÷ total target |

A single blended percentage divides a number that **includes** direct-dealer business by a target that **excludes** it.

## The order-booking definition

```
total OB = old party (P) + new party (Q) + direct dealer (J)
         = column I + column J
```

**Column I already equals P + Q.** Omitting new-party understated **116 of 170 active members**, one by 60 points.

## Always recompute

> **Never read a sheet percentage cell.** Always recompute from raw numerators and denominators. A per-member assertion checks against dashboard column AO and fires on mismatch.

## Zero-target members

Show **"no target recorded"**, never 0%. Report headline **and** like-for-like over targeted members only — Sandeep's team reads **62.3% headline against 58.7% like-for-like**, and Odisha's **107.0%** is one member contributing booking and no target.

# Part 3 — Elapsed months and pro-rating

**Only complete fiscal months count.** If today is 23 July, elapsed = 3 — April, May, June.

**Read column BD**, which holds elapsed months as a **number** per member, ranging 0.47 to 3.00. **Never derive it from a calendar.**

```
Cost Ratio % = ((monthly CTC × elapsed complete months) + YTD TA) ÷ YTD sale × 100
```

# Part 4 — Retailer and spread metrics

| Term | Definition |
|---|---|
| **Active retailer** | at least one order (OB > 0) in the current FY |
| **Dormant retailer** | listed in the working sheet, zero orders |
| **Business per retailer** | average OB per **active** retailer |
| **Top 5 / 10 OB share** | percentage of OB from the largest customers |
| **HHI** | `Σ (segment net ÷ total net × 100)²` |
| **Effective retailers** | **10,000 ÷ HHI** — prefer this to a raw HHI gauge |
| **Cross-sell depth** | average distinct segments per customer |
| **Win-back lead** | did business in a prior FY, no orders now, **and missing from the current working sheet** |

**HHI > 2,500 indicates high concentration** and dependency risk.

## The Removed Parties section

Each `Summary Report` tab holds active retailers first, **numbered in column A**, then a section header and removed retailers **with names but no serial**.

> **A parser keying on the name column reads straight through and inflates the count.** Stop on a section header **or** a name with no serial — a blank-run stop will not fire, because the header row is not blank.

Removed rows carry a **last-active year, not a removal date** — the sheet holds no removal date. Across one team, 224 removed retailers were 24–40% of every retailer those members had ever held.

# Part 5 — Visit plan and capacity

| Term | Definition |
|---|---|
| **Demonstrated visits per day** | visits done ÷ **that member's own** working days |
| **Annual capacity anchor** | total visits performed in the most recent **closed** FY — the realistic upper limit |
| **Feasible remaining** | annual anchor − visits done YTD |
| **Visit gap** | feasible remaining − remaining required. **Negative = shortfall** |
| **Pace ratio** | (visits done ÷ annual required) ÷ elapsed share of year |

**If no history exists**, project the demonstrated rate × 304 working days.

**Never use a team average** — working days range 11 to 75 across one team.

**Pace ratio is the construction that matters.** Raw coverage looks alarming for everyone; normalised, one member at 1.04 is on track while another at 0.52 runs at half rate.

Some members have **no annual visit requirement recorded** — guard every division and report **"not recorded"**, not 0%.

## The forward plan

| Priority | Who | Sorted by |
|---|---|---|
| **1 — Maintain** | active retailers | OB |
| **2 — Develop** | dormant retailers **with a distributor** | business plan ÷ max(distance km, 5) |
| **3 — Reduce** | visited repeatedly with zero OB | surfaced for frequency reduction |

**Retailers with no assigned distributor are excluded from scheduling** — they cannot order, so a visit cannot convert.

**The development pool decrements.** Each month draws the next tranche; when it runs out, print *"pool exhausted"* — an exhausted pool is itself a finding.

**The visit plan belongs to the salesperson, not the State Head.** Members with no mapped sheet get no plan at all.

# Part 6 — ROI

| Term | Definition |
|---|---|
| **Revenue-to-cost multiple** | total OB (or sale) ÷ total cost (CTC + TA) |
| **Cost ratio** | cost ÷ sales received. **Flagged above ~15%**, sector dependent |
| **Segment coverage %** | segments sold to at least one customer ÷ all available |

> **Revenue efficiency, not profit.** A high multiple can still be unprofitable if the mix is discount-heavy. **Never substitute MRP or purchase price for cost.**

# Part 9 — Identity

Two people are named **Ashutosh Kumar**: one under Anant Singh (Uttarakhand, Rudrapur), one under Sandeep Dadheech (Jharkhand, Dhanbad).

**Same person only if** name matches **and** State Head agrees **and** state agrees **and** headquarter is compatible.

**Any one of these proves they are different, with no override:** separate rows in the same tab for the same period; different head, state or headquarter in the same fiscal year.

> **Similarity can only suggest a match; geography can disprove one.** At 0.85 similarity, `Ranjit Kumar` merges with `Ankit Kumar` — different people, different heads. **Never auto-merge.**

- **`normSecKey`** keeps parentheticals — for database keys
- **`normName`** strips them — for roster joins. **Mixing them causes exactly the Ashutosh collision.**

# Part 10 — Thresholds

| Measure | Bands |
|---|---|
| **Achievement** | see the State Head glossary — **use one band set across both pages** |
| Cost ratio | flagged above ~15%, sector dependent |
| Visit gap | red if negative, green if positive |
| **HHI** | **> 2,500 = high concentration** |

> The implementation doc uses *Green ≥100 / Yellow ≥80 / Red <80* here, which conflicts with the State Head bands where <25% is Red. **A member at 60% would be Red on one page and Amber on the other.** Adopt the State Head set on both.

# Part 11 — Common misreadings

**"Achievement 48% means he will finish at 48% of plan."** No — that is against the **to-date** target. Annual progress is a different measure. Prasun: 48.5% achievement, 14.5% annual progress.

**"At risk means churned."** The year runs only to the cutoff.

**"Green means healthy."** Green means *measured and in band*. An unmeasured member shows nothing at all.

**"Achievement rose 6.7 points."** Check whether members left — excluding three departed members moved one team from 51.7% to 58.4%. **Organisational, not commercial.**

**"This state is over target."** Check for zero-target members.

**"Two members with the same achievement performed equally."** Check working days — 11 against 75 are not comparable.
